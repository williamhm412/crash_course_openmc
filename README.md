# Crash Course Openmc
This contains powerpoints and example code for crash course openmc. The course is designed to be given as 5 90 minute lectures. Each lecture will consist of half presentation/instruction and half hands on coding. Weeks 2-5 each come with example code as well as challenges for students to write their own code.
